# 진행상황 (PROGRESS)

> Claude / Codex / Gemini 공용 인수인계 문서. 규칙은 `AGENTS.md`의 "에이전트 협업 규칙" 참고.

## 현재 상태

- 단계: 제안서 등록과 협업 환경 설정을 마쳤다. 소스 코드, 빌드 설정, 실행 파일은 아직 없다.
- 기획 문서: [컴퓨터그래픽스 최종프로젝트 제안서](../컴퓨터그래픽스_최종프로젝트_제안서.docx)
- 개발 환경: C++과 OpenGL로 Windows PC용 3D 게임을 개발한다. 조작은 키보드와 마우스를 사용한다. 빌드 도구와 창·입력 라이브러리는 아직 정하지 않았다.
- 핵심 범위: 협곡 1개에서 원숭이가 동물 사이를 옮겨 탄다. 가젤은 균열을 도약하고, 들소는 바위를 돌진으로 부순다. 출구 도달 또는 체력 0에 따라 결과 화면을 표시한다.
- 담당: 장수현은 모델·애니메이션·화면 그리기(rendering)·사용자 인터페이스(UI)를, 김동형은 카메라·입력·대상 선택(picking)·게임 규칙·Windows 빌드를 맡는다.
- 제안서의 작업량 추정: 팀원당 기본 42시간과 오류 수정 여유 4시간.
- 마지막 갱신: 2026-11-11 (Codex)
